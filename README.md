# Olympics Data Analysis Using Python

## Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA) on an Olympics dataset using Python**. The objective is to explore athlete demographics, participation trends, medal distributions, country-wise performance, and differences across sports and genders.

The project uses **Pandas** for data manipulation and analysis, along with **Matplotlib and Seaborn** for data visualization.

---

## Objectives

The main objectives of this project are to:

* Understand and explore the Olympics dataset.
* Identify missing values and duplicate records.
* Clean the dataset by removing duplicate entries.
* Analyze the distribution of athletes by gender, age, height, and weight.
* Study medal distributions across different years.
* Analyze country-wise and sport-wise Olympic participation.
* Identify athletes with extreme physical characteristics such as maximum height and weight.
* Visualize Olympic trends using different charts and plots.

## How to Run the Project

1. Clone or download this repository.
2. Make sure Python and Jupyter Notebook are installed.
3. Install the required libraries:

```bash
pip install pandas matplotlib seaborn
```

4. Place 'dataset_olympics.csv' in the same directory as the notebook.
5. Open 'Olympics_Data_Analysis.ipynb' in Jupyter Notebook.
6. Run the cells sequentially to perform the complete analysis.
